# Devnandan website image prompts

This is the image brief for the website. Save generated files in `site/public/img/`. The current site uses SVG and CSS artwork in several places, so adding a new file alone does not replace that artwork. The filenames below are the handoff names for integration. The six delivered website slides already use genuine WebP screenshots; use the capture instructions at the end for those slides.

## Visual rules for every generated illustration

Use an original, premium technology editorial style that fits Devnandan IT Solutions. Deep navy `#0D111C` and card navy `#131A29`, electric blue `#2F8CFF`, deep blue `#1B4FC4`, white `#F4F7FB`, and cool muted blue-gray. Fine blue rim light, restrained gradients, clean geometry, realistic depth, soft shadows, sophisticated 3D and interface details. Avoid purple, lime, orange, stock-photo people, random logos, recognizable competitor interfaces, invented metrics, certification seals, and written words. Keep the subject centered within the middle 70% so the image can be cropped responsively. Render at the listed pixel dimensions, export WebP at high visual quality, and optimize toward 200 KB per image for the website. Use PNG only when transparency is required. The graphics should remain readable inside rounded cards in both dark and light site themes.

For prompts below, paste the individual prompt plus the visual rules above into your image generator. Generate each as a separate file. A generated image is concept art, not a screenshot of a client system.
